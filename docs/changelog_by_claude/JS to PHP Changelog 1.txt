### P0 — must fix (broken on fresh `database.sql`)

**1. `password` vs `password_hash` mismatch — student auth 100% broken.**
`database.sql:46` column is `password_hash`, but you write/read `password` in 5 places (verified by read):
`students/import.php:47`, `students/add.php:28`, `students/edit.php:39`, `exam_session/login.php:33,41`, `auth/authenticate.php:32,36`.
Fresh install → import throws `Unknown column 'password'` → rollback, login `password_verify` reads nonexistent column. Fix: rename all to `password_hash`. Also `import.php:78-79` inserts `null` into `mobile NOT NULL database.sql:40` / `date_of_birth NOT NULL :43` — change to `''`/validated date or alter schema.

### P1 — security / perf gaps

**2. CSRF partial.** `includes/csrf.php:14-92` + `csrf_field()` correct, verified on `submit.php:33`, `questions/add.php:20`, `import.php:13`, `save.php:23`. But `auth/login.php:18-21` and `exam_session/login.php:18-21` emit `csrf_field()` (`:286`, `:201`) yet never `csrf_verify()` — login-CSRF open. `exam_session/start.php:1-43` does state-changing `UPDATE ... started_at` via GET with no token/method check. Fix: verify on both logins (or remove dead fields), add `require_method('POST')` + token to `start.php`. Note `includes/helpers.php:128-137` `require_method()` has 0 call-sites + `defined('is_json_request')` bug — fix to `function_exists`.

**3. Indexes ship but never run.** `database_indexes.sql:11-37` has all 8 needed indexes, but not merged into `database.sql:30-298` and no installer references it. Fresh install = full scans + filesorts. Plus `ADD INDEX IF NOT EXISTS` is MariaDB-only, breaks MySQL 8. Fix: merge into `database.sql` + make migration MySQL-compatible (`CREATE INDEX` / existence check).

**4. Unbounded lists remain.** `includes/tests.php:66-100` `get_test_results($limit=0)` → `fetchAll` unbounded; callers `results/index.php:18`, `qr/index.php:17`, `pdf/result.php:21` never paginate (`count_test_results():146` exists, unused). `assignments/index.php:17-40` unbounded + slow `NOT IN (SELECT...)` — switch to `LEFT JOIN...IS NULL` + `LIMIT/OFFSET`.

**5. CSV import DoS + dead all-or-nothing.** `students/import.php:15-19` trusts `tmp_name`, no MIME/`finfo`, no size/row cap (`accept=.csv :127` client-only). One bad row → `rollBack :88` discards all. Fix: enforce 2MB / 5000-row cap, per-row try/catch with chunked commits, validate `mobile/DOB` formats.

**6. QR fallback still exfils PII.** Primary local `chillerlan\QRCode qr/image.php:50-62` is good. But fallback `:68-83` POSTs full `{uid,name,score}` to QuickChart, and `:68` label says “Encrypted” — it’s plain JSON. Fix: remove fallback or encrypt + relabel + log consent.
